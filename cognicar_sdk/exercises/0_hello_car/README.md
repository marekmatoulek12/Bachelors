# Exercise 0: hello car

**Edit** `hello_car.py` or `hello_car.cpp`. Complete the TODOs in order: lights,
logging, steering, motors, feedback, stopping, then checking the log.

**Run** with the simulator running:

```bash
python3 exercises/0_hello_car/hello_car.py --sim
```

C++: `cmake --build build --target hello_car -j2`, then `./build/hello_car --sim`.

**Check** that the car does what each TODO asks and that the last TODO prints
your log columns. Lights and servo feedback exist only on the real car
(run without `--sim`).
